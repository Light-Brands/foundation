# Say hello to Claude

Paste this into Claude Code inside your command center folder, or into Claude Desktop with the folder open.

Read CLAUDE.md in this project. Then do these steps, one at a time:

1. Say hello in one friendly sentence.
2. Tell me, in plain words, what CLAUDE.md says this project is.
3. Name the next setup step for my business and what it gives me.
4. If your command center folder is open in Claude Code, run npm run key:sync, then make the work commit with key/knowledge/system.md in it, then add an entry to the build log in key/log/ as docs/standards/log.md describes, in its own log-only commit made right after the work commit and naming that commit's id.

Do not change any files except the build log and key/knowledge/system.md.
