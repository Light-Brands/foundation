# Your first session with Claude

Paste this into Claude Code inside your command center folder, or into Claude Desktop with the folder open.

Read CLAUDE.md in this project. Then look at my command center and tell me, in plain words:

1. What is running today.
2. Which setup step is next, and what it gives my business.
3. Which three parts of my business, from the categories in my command center, would give me the most time back first, based on what I tell you about my business.
4. If your command center folder is open in Claude Code, add an entry to the build log in key/log/ as docs/standards/log.md describes, in its own log-only commit made right after the work commit and naming that commit's id, then run npm run key:sync.

If I upgraded from an earlier version, ask me to open System, then Settings, and press Save once so my Key holds my business details.

Ask me about my business one question at a time before you answer part 3. Do not change any files except the build log and key/knowledge/system.md.
