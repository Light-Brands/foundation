# Prompts

Every step of your command center has a prompt. Copy one, paste it into Claude, and Claude does the work with you.

| Prompt | Use it to |
|---|---|
| `first-session.md` | Get oriented and find your three biggest time savers |
| `work-with-claude.md` | Say hello to Claude and see your next setup step |
| `setup/get-claude-desktop.md` | 0.3.1: get Claude Desktop and open the Code tab on an empty folder |
| `setup/bring-in-your-foundation.md` | 0.3.2: bring your Foundation into that folder |
| `setup/connect-github.md` | 0.3.3: connect GitHub |
| `setup/connect-vercel.md` | 0.3.4: connect Vercel and choose your PIN |
| `setup/connect-your-database.md` | 0.3.5: connect your database |
| `setup/go-live.md` | 0.3.6: go live |
| `setup/change-my-pin.md` | 0.3.7: change your PIN |
| `setup/update-my-foundation.md` | 0.3.8: update your Foundation |
| `setup/own-domain.md` | 0.3.9: put it on your own domain |
| `update-system-docs.md` | Refresh the written record of what you have built, at the end of a build session |
