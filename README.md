# Your command center

The Dojo Foundation: one place to run your business, deployed in minutes and built out with prompts.

## Start

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FLight-Brands%2Ffoundation&env=FOUNDATION_PIN,FOUNDATION_BUSINESS_NAME&envDescription=Choose%20a%20PIN%20of%206%20to%2012%20digits%20to%20open%20your%20command%20center%2C%20and%20type%20your%20business%20name%20as%20you%20want%20it%20shown.&project-name=command-center&repository-name=command-center)

Press Deploy, choose a PIN, and your command center is live in about two minutes.

## Then

Open `prompts/first-session.md`, paste it into Claude, and Claude takes it from there. Every other step has a prompt in `prompts/`.
